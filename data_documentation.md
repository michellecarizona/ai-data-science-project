PM10 data

Environmental Protection Agency (EPA)

size: 11,697 rows × 21 columns

Column:	Description:
Date	Date the measurement was recorded
Source	Source of the data; AQS
Site ID	Unique identification number for the monitoring station
POC	Identifies the specific instrument/monitor used at the site
Daily Mean PM10 Concentration	Average PM10 concentration for that day; this is the main pollution variable
Units	Units of PM10 concentration, µg/m³
Daily AQI Value	Daily Air Quality Index associated with the PM10 measurement
Local Site Name	Name of the air-monitoring station
Daily Obs Count	Number of observations used for the daily value
Percent Complete	Percentage of expected measurements available for that daily observation
AQS Parameter Code	Code identifying the pollutant being measured
AQS Parameter Description	Description of the pollutant; PM10
Method Code	Code identifying the measurement method used
CBSA Code	Code for the metropolitan statistical area
CBSA Name	Metropolitan area; Phoenix–Mesa–Scottsdale, Arizona
State FIPS Code	Numerical code identifying Arizona
State	State where the monitoring station is located
County FIPS Code	Numerical code identifying the county
County	County where the monitoring station is located
Site Latitude	Latitude of the monitoring station
Site Longitude	Longitude of the monitoring station

Not every monitoring station has data for every day. Individual sites contain between about 290 and 365 days of observations, so days are missing for some stations even though individual reported rows are complete.
